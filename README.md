# UiPath Skills Site

Static navigator for UiPath Platform coding-agent skills.

The content model and source precedence are documented in [REFERENCE_SOURCES.md](./REFERENCE_SOURCES.md).

Open `index.html` locally, or serve the folder with any static web server.

## Structure

- `index.html` - skills navigator
- `graph.html` - knowledge graph view
- `app.js` - catalog data and home rendering
- `graph.js` - graph rendering and interactions
- `i18n.js` and `locales/` - language loading and translations
- `assets/` - images, flags, and lifecycle visual
- `REFERENCE_SOURCES.md` - authoritative repository and official documentation used to refresh the site
